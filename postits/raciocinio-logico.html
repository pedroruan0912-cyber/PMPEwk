Estruturas lógicas

O que é proposição

Frase declarativa que pode ser julgada verdadeira ou falsa, nunca as duas (princípios da não contradição e do terceiro excluído).

✔ "Recife é a capital de Pernambuco." (V)
✔ "2 + 2 = 5." (F, mas é proposição)

Não são proposições:

  • pergunta: "Quem estava de serviço?"
  • ordem: "Apresente o documento."
  • exclamação: "Que operação!"
  • sentença aberta: "x + 3 = 7", "Ele é sargento" (quem é ele?)
  • paradoxo: "Esta frase é falsa."

Frase com variável ou pronome indefinido ("ele", "aquela pessoa") é sentença aberta: não é proposição.

Estruturas lógicas

Quando cada um é V ou F

p ∧ qsó é V se as duas forem V
p ∨ qsó é F se as duas forem F
p ⊻ qV quando são diferentes
p → qsó é F em V → F
p ↔ qV quando são iguais

No condicional: se a 1ª é F, ele já é V; se a 2ª é V, ele já é V.

Vera Fischer é Falsa: o condicional só é falso com V na frente e F atrás.

"Se 2 + 2 = 5, então Recife fica na Bahia" é verdadeira: o antecedente é falso.

Estruturas lógicas

O condicional por dentro

p → q: p é o antecedente, q é o consequente.

p é condição suficiente para q · q é condição necessária para p.

Outras formas de dizer p → q:

  • "Quando p, q." · "q, se p." · "p implica q."
  • "p é suficiente para q." · "q é necessário para p."
  • "p somente se q."

Exemplo: "Se o PM está de serviço, está fardado." Estar de serviço basta para estar fardado; estar fardado é necessário para estar de serviço.

"p somente se q" é p → q, não q → p. E "necessário e suficiente" é o bicondicional.

Estruturas lógicas

Tautologia, contradição, contingência

Tautologiasempre V, em todas as linhas. Ex.: p ∨ ~p · (p ∧ q) → p
Contradiçãosempre F. Ex.: p ∧ ~p
Contingênciaàs vezes V, às vezes F. Ex.: p → q

Exemplo: "Choveu ou não choveu" é tautologia: é verdadeira em qualquer caso. "Choveu e não choveu" é contradição.

Para mostrar que não é tautologia, basta achar uma linha F. Para mostrar que não é contradição, basta uma linha V.

Estruturas lógicas

Calcular o valor lógico

Ordem: parênteses; depois ~, ∧, ∨, → e, por último, ↔.

Sendo p = V, q = F e r = V:

~p ∨ qF ∨ F = F
(p ∧ r) → qV → F = F
p ↔ ~qV ↔ V = V
(q ∨ r) ∧ ~pV ∧ F = F
q → (p ∧ ~r)F → … = V

Composta dada como verdadeira? Comece pela que só tem um jeito: E verdadeiro (tudo V), OU falso (tudo F) ou SE…ENTÃO falso (V e F).

Negação

Negando frases

"O PM está fardado e armado.""O PM não está fardado ou não está armado."
"Choveu ou a operação foi adiada.""Não choveu e a operação não foi adiada."
"Se o sinal fecha, a viatura para.""O sinal fecha e a viatura não para."
"Ou João é cabo ou é soldado.""João é cabo se e somente se é soldado."
"Todos os presos foram ouvidos.""Algum preso não foi ouvido."

"Não é verdade que…" e "é falso que…" são negações da frase inteira.

A negação do "se…então" não tem "se": é uma frase com E. Desconfie da alternativa que nega com outro condicional.

Equivalência

Equivalências do condicional

p → q ≡ ~q → ~pcontrapositiva: troca de lugar e nega as duas
p → q ≡ ~p ∨ qnega a primeira, troca por OU, mantém a segunda

Exemplo: "Se estudo, passo."
≡ "Se não passo, não estudo."
≡ "Não estudo ou passo."

Não são equivalentes a p → q:

  • q → p (recíproca): "Se passo, estudo."
  • ~p → ~q (inversa): "Se não estudo, não passo."

Contrapositiva: volta negando. Para o OU: NEOUMA, NEga, OU, MAntém.

Equivalência

Outras equivalências

p ↔ q≡ (p → q) ∧ (q → p) ≡ ~p ↔ ~q
p ∨ q≡ ~p → q ("se não p, então q")
p ⊻ q≡ ~(p ↔ q)
~(p ∧ q)≡ ~p ∨ ~q (De Morgan)
~(p ∨ q)≡ ~p ∧ ~q (De Morgan)
p ∧ q · p ∨ q≡ q ∧ p · q ∨ p (a ordem não importa)
p ∧ (q ∨ r)≡ (p ∧ q) ∨ (p ∧ r) (distributiva)
p ∨ (p ∧ q)≡ p (absorção)
(p ∧ q) → r≡ p → (q → r)

No condicional a ordem importa: p → q não equivale a q → p.

Na dúvida, monte a tabela-verdade das duas: colunas iguais = equivalentes.

Implicação lógica

Implicação × equivalência

Equivalência
p ⇔ q		as duas têm a mesma tabela-verdade; p ↔ q é tautologia
Implicação
p ⇒ q		sempre que p é V, q também é; p → q é tautologia

Implicações que caem:

  • p ∧ q ⇒ p (simplificação)
  • p ⇒ p ∨ q (adição)
  • (p → q) ∧ p ⇒ q (modus ponens)
  • (p → q) ∧ ~q ⇒ ~p (modus tollens)

→ é um conectivo (forma uma nova proposição). ⇒ é uma relação entre proposições. Equivalência é implicação nos dois sentidos.

Quantificadores

Todo, algum, nenhum

∀ universaltodo, qualquer, cada, para todo
∃ existencialalgum, existe, há, pelo menos um
∄nenhum, não existe (= todo… não)

O quantificador transforma a sentença aberta em proposição: "x > 2" não é proposição; "existe número natural x > 2" é (V); "todo número natural é maior que 2" também é (F).

"Algum PM é atleta" significa "pelo menos um". Continua verdadeira mesmo que todos sejam atletas.

Diagramas lógicos

Tirar conclusões com diagramas

Método: desenhe primeiro o "todo" e o "nenhum", depois o "algum". A conclusão só vale se aparecer em todos os desenhos possíveis.

Todo PM é servidor. Nenhum servidor é empresário.✔ Nenhum PM é empresário.
Algum PM é músico. Todo músico é artista.✔ Algum PM é artista.
Todo PM é servidor. Algum servidor é atleta.✘ "Algum PM é atleta" não dá para concluir: os atletas podem estar fora dos PMs.
Todo PM é servidor.✘ "Todo servidor é PM."

"Todo A é B" não quer dizer "Todo B é A": B pode ser maior.

Argumentação

Argumento válido

Argumento = premissas (P1, P2…) + conclusão.

Válido: se as premissas forem V, a conclusão é obrigatoriamente V. Quem garante é a forma, não o assunto.
Inválido (sofisma ou falácia): dá para ter premissas V e conclusão F.

Todo peixe voa. Todo cão é peixe. Logo, todo cão voa.✔ válido (premissas falsas, forma correta)
Todo PM é servidor. João é servidor. Logo, João é PM.✘ inválido

Na prova, trate as premissas como verdadeiras, mesmo que pareçam absurdas. Validade não é verdade.

Regras de inferência

Exemplo de modus tollens: "Se houve arrombamento, a porta está danificada. A porta não está danificada. Logo, não houve arrombamento."

Argumentação

Resolver em 4 passos

  1. Considere todas as premissas verdadeiras.
  2. Comece pela premissa simples (ou por um E, que só é V de um jeito).
  3. Descubra os valores e vá substituindo nas outras.
  4. Marque a alternativa que fica obrigatoriamente V.

P1: Se João estuda, passa. P2: Se passa, toma posse. P3: João não tomou posse.
P3 é V → "passa" é F (P2) → "estuda" é F (P1). Conclusão: João não estudou.

É válido? Suponha a conclusão F e tente deixar todas as premissas V. Se conseguir, o argumento é inválido.

Dedução, indução, analogia

Deduçãodo geral para o particular; conclusão necessária. "Todo PM fez curso de formação; Ana é PM; logo, Ana fez o curso."
Induçãode casos para uma regra; conclusão provável. "Os 5 cães que vi latiam; todo cão late."
Analogiaconclui por semelhança entre casos. "Deu certo no 1º BPM, vai dar certo no 2º."
Inferênciao ato de tirar uma conclusão das premissas

Analogia em questão: "Médico está para hospital assim como professor está para…" → escola. Descubra a relação (lugar, função, parte e todo, oposto) e repita.

Verdades e mentiras

Um dos três suspeitos furtou. Só um mente.
A: "Foi o B." · B: "Foi o C." · C: "Não fui eu."

1. B e C se contradizem: um dos dois mente.
2. Como só há um mentiroso, A fala a verdade.
3. Foi o B. Confere: B mente, C diz a verdade.

Sem contradição à vista? Teste hipóteses: "se o culpado for A, quantos mentem?" e fique com a que bate com o enunciado.

Duas falas contraditórias (uma nega a outra): exatamente uma é V. Comece por elas.

Probabilidade: o básico

P = favoráveis ÷ possíveisde 0 (impossível) a 1 (certo), ou de 0% a 100%

Moeda: cara1/2
Dado: número maior que 42/6 = 1/3
Dois dados: soma 76/36 = 1/6 (1+6, 2+5, 3+4, 4+3, 5+2, 6+1)
